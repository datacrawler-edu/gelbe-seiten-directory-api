# Export listings from Apify
1. Open [Gelbe Seiten Scraper](https://apify.com/datascraperes/gelbe-seiten-business-directory?fpr=edudata).
2. Enter `Zahnarzt` and `Berlin`, then limit the search to five listings.
3. Click **Start** and wait for the run to finish.
4. Open **Dataset** to inspect listings and export CSV or JSON.
5. Open the `SUMMARY` record to check the stop reason before using the export.
